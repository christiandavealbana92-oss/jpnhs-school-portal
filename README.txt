JPNHS SCHOOL PORTAL

ROLES
- Administrator: username Administrator / password isAdmin1234. Administrator can manage school settings, staff, portal status, backups, and VIEW which features are unlocked.
- VA: private owner area available through Index > Other Options > VA Access. VA controls feature unlocks and plan activation.
- Student, Teacher, Registrar: normal school roles.

There is NO Super Admin role/page. super-admin.html was replaced by admin.html.

IMPORTANT: The Administrator username/password are implemented in the frontend for this static prototype. For production security, move authentication/authorization to Firebase Authentication + Realtime Database rules or a trusted backend; never rely on hidden menus or frontend credentials alone.
