JPNHS PORTAL UPDATE
===================

1. Registrar student editing updates the existing Student ID.
2. Teacher grade entry is matched to teacher assignments and enabled school levels.
3. Administrator Configuration now uses grade-level checkboxes from Kindergarten through College 4.
4. Only Administrator-selected grade levels are available to Registrar enrollment, sections, reports, and teacher assignments.
5. Subjects are now managed by the Registrar, not Administrator.
6. Administrator configuration saves schoolYear, gradingSystem, and gradeLevels directly inside the school record in one Firebase write.
7. The old separate gradeLevels/subjects/strands configuration writes were removed; this fixes the common PERMISSION_DENIED error caused by those extra database paths.
8. No Super Admin role was added.


Community Feed Update
- Generic school-branded main feed.
- Text-only posts, announcements, and multi-person call-outs.
- Call-outs support ID Search or Name Search.
- Notifications link directly to the referenced post.
- Poster can delete their own post; Administrator can delete any post.
- VA remains private and is not shown in the main portal menu.
